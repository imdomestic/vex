## 当前接口

- `POST /v2/auth/device` 请求 `{}`，返回 `{handle,userCode,verificationUri,interval,expiresAt}`。
- `POST /v2/auth/device/poll` 请求 `{handle,client}`；202 返回 `{status:"pending",interval}`；200 返回 `{token,user,expiresAt}`，客户端兼容附加会话字段。
- `expired_token`、`access_denied`、`account_not_linked` 分别显示超时、拒绝授权和账号尚未加入服务器的提示。会话失效继续按当前服务器处理。
- 准备下载 `GET /v2/projects/{project}/rooms/{room}/pack.mrpack?buildId={build}&generation={generation}`；两个条件取自同一次 start 响应，包内 versionId 精确校验为 `<room>-g<generation>-<build>-a<attempt>`。
- `GET /v2/projects/{project}/pulls` 返回 PR 列表；`rooms` 为 loader 到房间 ID 的映射，`builds` 为 loader 到当前 head 可用 Build ID 的映射。房间的 `pr` 元数据包括 number/title/author/url/headSha/fromFork。
- PR 地址为 `ruri://vex?server=<baseURL>&project=<project>&room=<room>`。使用 URLComponents；重复参数、额外参数、userinfo、fragment 与带凭据的服务器地址均拒绝。

客户端指纹对运行时与客户端文件内容计算，与文件名和服务器专用 agent 无关。固定向量摘要为 `e6913c10065a3d1efd42dec55173b7cf8373a9299f438b601611b45ab128d3a9`。
